# dl

深度学习练习脚本集。不打包、不建包,每个 `.py` 是一个独立可运行的小实验。

## 环境

Python 3.15 + uv 管理虚拟环境(`.venv/`),依赖见 `pyproject.toml`。

```bash
uv sync              # 安装/更新依赖
uv add <pkg>         # 新增依赖
```

## 运行

```bash
uv run python 01_autograd_mlp.py
```

因为项目根目录在 `sys.path` 上,脚本之间可以互相 `import`,例如 `from utils import foo`。

## 脚本

| 文件 | 内容 |
|---|---|
| `01_autograd_mlp.py` | 用 autograd 手写两层 MLP 拟合 XOR,手动梯度下降 |
| `02.py` | 线性回归拟合导弹轨迹(输入 t 和 t²,无隐藏层) |
| `021（激活函数）.py` | 单隐层 1-16-2 网络,tanh 激活,可换激活函数对比拟合效果 |
| `022（向量场）.py` | 把 021 的「t → 位置」改成「(vx,vy,k) → 加速度」,训练场模型与位置模型,导出给网页 |

`022` 配套两个文件:

- `022（向量场）.html` — 抛体仿真页面:拖 v0 / 角度 / 阻力系数,同时画出真实轨迹、场模型预测、021 位置模型预测
- `022_model.js` — 由 `022（向量场）.py` 自动生成的权重,勿手改

网页支持 URL 参数直接指定初始状态,例如 `022（向量场）.html?v0=20&ang=40&k=0.03`。
